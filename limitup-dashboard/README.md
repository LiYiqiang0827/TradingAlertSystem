# TradingAlert 涨停研究台

与 `offlineAlertSystem/` 同级的本地 HTML 原型，默认只读访问 Mac mini 上 TradingDataManager / TradingDataBase 的现有数据。

## 启动

在 Mac mini 项目目录运行：

```bash
cd ~/TradingAlertSystem/limitup-dashboard
PYTHONPATH="$HOME/TradingDataManager:$HOME/TradingDataManager/offlineDataManager/scripts" \
  .venv/bin/python server.py
```

如果 TradingDataManager 虚拟环境位置不同，可使用已安装有 pandas、SQLite 和数据 provider 依赖的 Python。默认监听 `127.0.0.1:8765`。浏览器打开 `http://127.0.0.1:8765/`。

## 数据与缓存

- 题材、个股涨停原因：`~/TradingDatabase/theme_graph/每日涨停原因/YYYYMMDD.md`
- 涨停池：优先 `tbl_cn_kpl_list`，当日没有数据则使用 `tbl_cn_kpl_limit_performance`
- 日线预载 2 年、周线预载 5 年、月线载入当前数据库中的全部历史，1 分钟预载最近 5 个交易日，15 分钟载入最近 3 个月
- 每个周期独立缓存到 Redis DB 2，键按股票、周期、截止日期区分，复盘日数据缓存 7 天，最新行情缓存 5 分钟；缓存命中后不重复读取 data provider
- 选中个股时同时预载复盘日与数据库最新行情并写入 Redis，图表一次载入两段数据；“最新K线”按钮只滚动显示范围，不请求接口、不重取数据；最新行情缓存 5 分钟
- 1 分钟图只使用 1 分钟表，15 分钟图只使用 15 分钟表；15 分钟表覆盖不足时显示实际覆盖区间，不用 1 分钟数据拼接替代
- 浏览器用内存 + IndexedDB 双层缓存行情：内存命中最快，页面刷新后可从 IndexedDB 恢复；两层各按先进先出保留最多 30 只不同股票，每份缓存 24 小时过期；新增第 31 只时淘汰最早写入的股票，复盘日期变更时同一股票重新读取并更新缓存
- 服务端优先使用本机 Redis `127.0.0.1:6379/2`；Redis 不可用时仍回退到项目内 SQLite 持久缓存 `cache/dashboard-cache.sqlite3`
- Redis 服务不可用时原型仍可启动。Redis 不会由本项目自动安装或启动

## 涨停天梯预载与缓存

- 首次打开、通过日历切换截止日：读取并绘制截至该日的最近 20 个有行情数据的交易日；不足 20 日时使用全部可用日期。
- 日期滑条和左右键优先复用已载入的原始数据，只在鼠标释放后重新计算截止日可见的题材、节点和连线；不展示截止日之后的节点，也不使用未来节点决定题材归类。
- 画布接近已载入范围左侧时，提前补载下一批 20 日（与上一批重叠 1 日以衔接晋级路径）；拖动中完成的补载延至释放鼠标后绘制，保留当前视野。
- 服务端 Redis 键使用 `limitup-ladder:v12:截止日:交易日数:数据库版本`。历史窗口缓存 24 小时，当日窗口缓存 5 分钟。
- 浏览器内存和 IndexedDB 各保留最多 24 份数据块；刷新页面后可恢复 IndexedDB 缓存，同一版本的并发请求合并。
- `/api/ladder-version` 依据 KPL、日线数据库及非空 WAL 的大小和修改时间生成版本。浏览器最多每 30 秒校验一次版本；源库更新或历史修复后旧数据块不再复用。
- 题材颜色在当前页面会话内持续保留，拖动或日历切换不会给已有题材重新排色。
- 首次计算通过候选交易日的索引存在性查询、近期涨停前驱索引和按需历史锚点查询，避免全表日期去重和逐股远期回溯；日线在内存中统一排序，保持停牌、跨日形态及晋级链的原有口径。

## 天梯展开状态与图例导航

- 首次打开时，所有板数的未晋级列表、首板和破板的“其他题材”统一默认收缩，工具栏显示“展开”；三板及以上题材内的未晋级股票也使用折叠列表。
- 工具栏“展开/收缩”统一控制这些列表；双击三板及以上的未晋级控件只控制三板、四板和高板，二板仍单独控制。
- 图例默认勾选“指定日”，并按题材最高板收缩归类；圆圈显示该题材当日全部涨停数，大小随数量变化。高板旁的“展开/收缩”可切换为各板分别列出。
- 图例指定日超出画布当前可见日期范围时，同步调整画布截止日和右侧日历；范围内只改变图例。
- 图例悬浮框左上角题材名单击进入题材页面：指定日模式使用该日，区间模式使用区间末日；页面保留返回涨停天梯的入口。
- 主画布题材名单击聚焦并压缩题材；股票名单击仅按股票代码高亮跨日期标签及连线，其他股票淡出，不改变几何布局或滚动位置。再次单击同股、Esc 或“全”恢复；双击仍进入对应页面，返回天梯保留聚焦。悬浮框中的链接保留单击跳转。

## 紧凑天梯的再次首板连线

- 仅题材聚焦/板数筛选后的紧凑版面显示新增虚线；回溯 10 个交易日内同股票最近一次已确认的断板或首板破板，不连接正常连板、几天几板续连或纯停牌后直接晋级的路径。
- 新增边单独缓存和绘制，不参与晋级率、板数或晋级链题材合并。符合条件的再次首板，股票板数框改为正方形并保留一字、T 字、强弱板的描边规则。
- 出口已有“停”圈或红叉时复用原标记，仅没有这些出口时补“续”圈；多股标签的虚线进入该股票行左侧内部窄槽的专属“续”圈，单股标签复用原计数圈；原计数圈始终贴住矩形外缘。入口圆圈显示上一次涨停状态（破、板数或板数/天数），右侧显示断开日期与交易日间隔，出口小字保留再次涨停日期与间隔。
- 间隔按交易日历从实际断板/破板日算至再次涨停日；缺失日线不视为已确认断板，所有候选日期不超过所选截止日。

## 未晋级归类与续接入口

- 每条未晋级记录只归属一次：按昨日板数加一的冲击档位分组，五板及以上合并到高板，不再同时复制到首板汇总。题材卡内部有对应档位时放卡内，否则放该档的未晋级汇总；前板数缺失的记录才使用首板兜底。
- 股票聚焦期间隐藏未晋级标题及数量入口，保留布局和该股票自身的历史记录；取消聚焦后恢复。
- 断板续连、停牌续接和再次首板采用相同的细虚线样式；聚焦股票后，相关路径使用一致的高亮样式。
- 单股题材标签复用原左侧计数圈作为续接入口。多股标签保留贴住矩形外缘的计数圈，另在左侧内部窄槽按股票行设置“续”圈，两种圈都与矩形边缘相接。

## 天梯题材悬浮名单

- 悬停图中题材名称，显示标签当日、当前统一题材归属下的完整涨停名单，固定按高板（5 板及以上）、四板、三板、二板、首板分组；空组显示横线。N 天 M 板按 M 板分组，圈内保留 M/N。
- 列表包含板数圈、股票名称、当日涨幅、首次涨停时间、封板金额和简略原因；一字/T 字红色实线圈、强板红色虚线圈、弱板题材色虚线圈。创业板与科创板股票名在表格和天梯中均为红色。
- 封板金额与涨幅按日期从本地行情表批量读取；简略原因复用 Neo4j 当日归因，优先对应题材，兼容旧日报题材标题后按股票代码匹配，缺失显示横线。
- 补充字段通过 `/api/ladder-topic-details` 延迟加载，不增加 20 日初始数据体积；服务端 Redis 和浏览器内存缓存 5 分钟，同日请求复用。列表可独立滚动，点击股票可进入个股页，移开鼠标或 Esc 关闭。

## 图表

内置 [KLineChart](https://github.com/klinecharts/KLineChart) 10.1.0 UMD 构建和 Apache-2.0 许可文件；本地运行无需 CDN。日线、周线、月线和 15 分钟图将 MA(5/10/20/30/60/120/250) 叠加在 K 线上；所有周期的成交量副图显示 VOL 及 5/10/20/60 均量。

选中文字后点击“分析这段”，当前原型会从对应日报提取题材催化与个股逻辑字段。它尚未调用生成式模型。


## 2026-10-25 回归修复与缓存

- 每日行情、个股和指数请求均校验请求序号与当前路由。切日期、切页面后迟到的响应及错误不会覆盖当前页面；日期加载的调用方同样停止过期导航，返回日期异常时显示读取失败。
- 破板列表遇到短暂网络失败，最多自动重试两次（500 / 1000 毫秒）；成功后清除错误状态，旧视图的重试不会重绘当前页面。指定日图例及题材、日期、个股基本信息悬浮窗拒绝混合不同数据库版本的数据。
- 可用交易日列表按行情数据库及 WAL 文件版本缓存；异常降级结果不缓存，调用方得到独立列表。完整每日总览缓存 60 秒，底层归因摘要缓存 5 分钟，行情或指数库版本变化立即使用新键。题材悬浮原因复用同版本摘要。
- 同一缓存键的并发冷请求合并计算；SQLite 备用缓存使用连接级锁保护查询、写入、过期清理和提交。
- 天梯绘图预先按日期、板数、题材建立索引，续接入口使用集合查找，保留排序与路径口径。直接进入天梯、题材或指数时跳过临时每日总览的绘制和附带请求。JSON 大响应在浏览器支持时使用 gzip，尊重禁用 gzip 的请求。
- 隔离回归（不访问生产数据库）：在本目录执行 `python3 tests/test_dashboard_cache.py` 和 `node tests/test_dashboard_navigation.cjs`。
- 真实行情回归以 20260901、20261008、20261016、20261023 的 20 交易日窗口对比新旧完整节点、晋级路径、停牌路径和首板续接结果。性能数字需区分首次生成、缓存命中与浏览器绘图，不能将缓存命中时间当作首次计算时间。


### 单股聚焦与时间轴重绘

- 单股聚焦期间关闭题材卡与连线的透明度过渡，重绘前设置聚焦标记，避免拖动或补载数据时短暂显示全部题材。
- 日期窗口没有选中股票的节点时仍保留聚焦；拖回该股票出现的日期会恢复对应脉络。同页数据版本刷新也保留选中的股票。取消聚焦后恢复原有题材交互。


### 天梯图例股票列表

- 点击题材计数圆圈展开或收起股票列表，题材文字保持原有单击聚焦与双击独占聚焦；指定日图例的展开、收缩以及非指定日范围模式均支持。
- 高板标题的分组按钮旁有默认不勾选的“显示股票”，批量展开或收起当前及后续图例。每个板数分组内的题材行可独立覆盖该状态，混合状态用半选标识。
- 指定日显示当日对应分组股票；范围模式按股票代码去重并保留范围内最新记录。列表单行显示板数徽标、名称、涨幅、涨停时间和封板金额；徽标复用天梯的一字/T字、强弱板、几天几板样式。
- 列表显示时左侧适当加宽；涨幅与封板金额按日期复用现有题材详情缓存，仅为已展开名单请求补充数据，同时最多四个日期请求。股票行单击切换到该题材并压缩行高，只显示该股的节点、晋级、断板与续接路径，双击进入个股页面，返回后保留列表状态。


- 左栏单股紧凑模式补出首板代表视图中省略的实际节点，保持原日期列宽与题材晋级数量统计；图例和股票列表保留。重复单击股票仍保持该股紧凑模式，不做取消切换。日历、时间轴和个股页返回会保留此状态；“全”、题材选择及 Esc 可退出。

- 左栏股票名悬停复用个股基本信息、5日分时、日K和15分钟行情悬浮窗，行情截止该行对应日期；单击保持单股紧凑脉络，双击进入个股页面。
